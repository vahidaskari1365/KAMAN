# بایگانی

سامانه مدیریت و بایگانی قراردادهای سازمانی با جستجو، فیلتر، آپلود فایل‌های اسکن‌شده، گزارش‌ساز و اعلان خودکار قراردادهای رو به اتمام.

## ویژگی‌ها
- مدیریت سازمان‌ها و قراردادها (خرید/فروش و خدمات/پشتیبانی به‌صورت جداگانه)
- جستجوی پیشرفته بر اساس شماره قرارداد، سازمان، نوع، وضعیت
- آپلود فایل‌های اسکن‌شده (تصویر / PDF) با مشاهده‌ی inline
- گزارش‌ساز با فیلتر و پرینت با انتخاب اندازه‌ی برگه (A4 / A5 / Letter / Legal)
- اعلان خودکار قراردادهای نزدیک به پایان
- مدیریت کاربران با نقش‌های مدیر / کاربر / بیننده
- تقویم شمسی (جلالی) و اعداد فارسی
- تم روشن / تیره، کاملاً RTL و ریسپانسیو
- رنگ‌بندی برند kaman.ir (آبی #046BD2)

## اجرای محلی (توسعه)
```bash
bun install
bun run db:push
bun run dev
```
سپس به http://localhost:3000 بروید. داده‌های نمونه به‌صورت خودکار ساخته می‌شوند.

## دیپلوی دمو روی Render (یک‌کلیکی)
۱. به https://render.com/deploy?repo=https://github.com/vahidaskari1365/KAMAN بروید.
۲. نام سرویس را تأیید کنید (مثلاً `kaman-archive`).
۳. روی **Apply** بزنید. Render خودکار `bun install` و `bun run build` و سپس `bun run start` را اجرا می‌کند.
۴. پس از چند دقیقه یک URL عمومی مثل `https://kaman-archive.onrender.com` می‌گیرید.
۵. داده‌های نمونه در اولین بارگذاری داشبورد خودکار ساخته می‌شوند.

> توجه: پلن رایگان Render پس از ۱۵ دقیقه غیرفعالیت سرویس را به خواب می‌برد (سرد استارت ~۵۰ ثانیه). برای دمو کافی است. برای نسخه‌ی دائمی به پلن پولی با دیسک ماندگار ارتقا دهید.

## انتقال به سرور اختصاصی (مرحله‌ی بعد)
این پروژه از SQLite + ذخیره‌ی محلی فایل استفاده می‌کند. برای سرور اختصاصی با دیسک دائمی (VPS / سرور شرکت):
۱. کد را روی سرور کلون کنید.
۲. `DATABASE_URL=file:/var/lib/kaman/custom.db` (یا هر مسیر دائمی) را در `.env` تنظیم کنید.
۳. `bun install && bun run build && bun run start` را اجرا کنید.
۴. برای پایداری از systemd یا pm2 استفاده کنید.
